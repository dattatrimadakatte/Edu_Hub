# How to Generate Visual Diagrams

## Method 1: Using PlantUML Online
1. Go to **http://www.plantuml.com/plantuml/uml/**
2. Copy the content from any `.puml` file
3. Paste it in the text area
4. Click "Submit" to generate the diagram
5. Download as PNG/SVG

## Method 2: Using Draw.io
1. Go to **https://app.diagrams.net/**
2. Create new diagram
3. Use the specifications from the `.md` files to draw manually

## Method 3: Using VS Code
1. Install "PlantUML" extension
2. Open any `.puml` file
3. Press `Alt+D` to preview
4. Right-click → Export to save as image

## Files Created:
- `ER_Diagram.puml` - Entity Relationship diagram code
- `UseCase_Diagram.puml` - Use Case diagram code  
- `DFD_Level0.puml` - Context diagram code
- `DFD_Level1.puml` - Level 1 DFD code
- `ASCII_Diagrams.md` - Text-based diagrams for reference
